## Problem Statement

<div class="header"><div class="title">D. Serval and Kaitenzushi Buffet</div><div class="time-limit"><div class="property-title">time limit per test</div>2 seconds</div><div class="memory-limit"><div class="property-title">memory limit per test</div>256 megabytes</div><div class="input-file input-standard"><div class="property-title">input</div>standard input</div><div class="output-file output-standard"><div class="property-title">output</div>standard output</div></div><div><p> </p><p>Serval has just found a Kaitenzushi buffet restaurant. Kaitenzushi means that there is a conveyor belt in the restaurant, delivering plates of sushi in front of the customer, Serval.</p><p>In this restaurant, each plate contains exactly $$$k$$$ pieces of sushi and the $$$i$$$-th plate has a <span class="tex-font-style-it">deliciousness</span> $$$d_i$$$. Serval will have a meal in this restaurant for $$$n$$$ minutes, and within the $$$n$$$ minutes, he must eat up <span class="tex-font-style-bf">all</span> the pieces of sushi he took from the belt.</p><p>Denote the counter for uneaten taken pieces of sushi as $$$r$$$. Initially, $$$r=0$$$. In the $$$i$$$-th minute ($$$1\leq i\leq n$$$), only the $$$i$$$-th plate of sushi will be delivered in front of Serval, and he can do <span class="tex-font-style-bf">one</span> of the following:</p><ul> <li> Take the $$$i$$$-th plate of sushi (whose <span class="tex-font-style-it">deliciousness</span> is $$$d_i$$$) from the belt, and $$$r$$$ will be increased by $$$k$$$; </li><li> Eat one uneaten piece of sushi that he took from the belt before, and $$$r$$$ will be decreased by $$$1$$$. Note that you can do this only if $$$r \gt 0$$$; </li><li> Or, do nothing, and $$$r$$$ will remain unchanged. </li></ul><p>Note that after the $$$n$$$ minutes, the value of $$$r$$$ <span class="tex-font-style-bf">must</span> be $$$0$$$.</p><p>Serval wants to maximize the sum of the <span class="tex-font-style-it">deliciousnesses</span> of all the plates he took. Help him find it out!</p></div><div class="input-specification"><div class="section-title">Input</div><p>Each test contains multiple test cases. The first line contains the number of test cases $$$t$$$ ($$$1 \le t \le 10^4$$$). The description of the test cases follows. </p><p>The first line of each test case contains two integers $$$n$$$ and $$$k$$$ ($$$1\leq k \lt n\leq 2\cdot 10^5$$$) — the number of minutes of the meal and the number of sushi pieces in each plate.</p><p>The second line contains $$$n$$$ integers $$$d_1, d_2, \ldots, d_n$$$ ($$$1\leq d_i\leq 10^9$$$) — the <span class="tex-font-style-it">deliciousness</span> of each plate.</p><p>It is guaranteed that the sum of $$$n$$$ over all test cases does not exceed $$$2\cdot 10^5$$$. </p></div><div
