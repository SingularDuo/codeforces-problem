Here, it aims to explore the Bermuda Rectangle. Of course, it poses no danger to The Beaver, but it is interesting from a scientific perspective.</p><p>Unlike the Bermuda Triangle, not much is known about the Bermuda Rectangle. Specifically, The Beaver knows for sure that the area of the rectangle is $$$S$$$, its sides are integers, and the bottom left corner is located at the point $$$(0, 0)$$$.</p><p>The Beaver is interested in how many cells from a rectangle with sides $$$x$$$ and $$$y$$$, whose bottom left corner is at the point $$$(0, 0)$$$, can be located within the Bermuda Rectangle. A cell is considered to be within the Bermuda Rectangle if there exists a rectangle that satisfies the given constraints of the Bermuda Rectangle and contains that cell. Help The Beaver quickly respond to queries! You need to answer $$$q$$$ such queries.</p></div><div class="input-specification"><div class="section-title">Input</div><p>Each test contains multiple test cases. \le 10^{14}$$$; $$$1 \le q \le 3 \cdot 10^5$$$).</p><p>This is followed by $$$q$$$ lines, each containing two integers $$$x, y$$$ — the next query ($$$1 \le x, y \le S$$$).</p><p>It's guaranteed that the sum of $$$q$$$ over all test cases doesn't exceed $$$3 \cdot 10^5$$$.</p><p>It's guaranteed that the sum of $$$\sqrt{S}$$$ over all test cases doesn't exceed $$$10^7$$$.</p></div><div
